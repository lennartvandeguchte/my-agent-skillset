# Values

Edit by hand. The agent reads this file at the start of every harvest and every session.
Values are the filter: a problem that fails them is dropped, whatever its domain.
Domains are the steering: the harvester looks *there*, not everywhere.

## Values

- **Circularity**: materials, products and data that loop instead of ending.
- **Sustainability**: less extraction, less waste, longer life.
- **AI for good**: intelligence applied to problems that matter, not attention.

## Domains

Narrower than the values. The harvester searches inside these; the council reasons inside these.
Add, remove or reorder freely. Order is priority.

1. Textile waste
2. Repair over replacement
3. Food and compost systems
4. Product passports

## Anti-patterns

Things that technically fit the values but that I do not want to build. The agent treats these as hard rejects.

- Anything whose business model is attention, engagement or ads.
- "Awareness" apps. If the user already knows the problem exists, telling them again is not a product.
- Marketplaces that need two sides to show up before anyone gets value.
- Carbon-offset accounting, ESG dashboards for reporting's sake.
